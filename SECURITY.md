# Security Policy

## Reporting a Vulnerability

We take the security of the CSJMU RAG System seriously. If you find a security vulnerability, please report it to us responsibly instead of opening a public GitHub issue.

Please email security reports to **security@csjmu.ac.in**.

Include the following details in your report:
- Type of vulnerability (e.g., SQL injection, remote code execution, credentials leak)
- Step-by-step instructions to reproduce the issue
- Potential impact of the exploit

We will acknowledge receipt of your report within **48 hours** and provide a timeline for a resolution/patch.
